Sensor node

Turns this phone or laptop into a noise sensor for the map. It uses this device's microphone, measures the level in dB(A), and sends each 5-second clip to be classified the same way as the Raspberry Pi.

2 · Calibrate the microphone Not calibrated

Every microphone hears loudness a little differently. Calibrating makes this device read the same dB as the reference.

  1. Put this device right next to the reference (the Raspberry Pi, or a sound meter).
  2. Play steady test noise nearby, about as loud as a busy street. Any device can play it with the button below.
  3. Press Measure and keep still for 15 seconds.
